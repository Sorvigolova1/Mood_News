1)Запуск: npm run dev
2)Откуда новости: RSS Lenta.ru; список через getNews (rss-parser), полный текст по клику через cheerio (селектор .topic-body__content-text);
3) Хранение данных через IndexedDB, установлен таймер 15 минут,после истечении которого обновляется список постов и сохраняется в кэш.
4)Переписывание тона происходит с помощью LLM Deepseek, передается prompt, а ответ нейросети приходит в формате стриминга,результат в cache[mood]
5)Контроль фактов:правила сохранения фактов описываются в prompt`е
6)Использовал: Deepseek,Gemini,Claude.
